Vercel Deployment

इस पूरे प्रोजेक्ट में vercel.json पहले से कॉन्फ़िगर है। आप इसे 1 मिनट में अपने Vercel खाते पर रीडिप्लॉय कर सकते हैं।

⚡ 1-क्लिक Vercel स्टेप्स:

💾 डेटा बैकअप व क्रॉस-प्लेटफ़ॉर्म सिंक (Android ⇄ Web ⇄ iOS)

Android ऐप से एक्सपोर्ट किया गया JSON बैकअप यहाँ इम्पोर्ट कर सकते हैं, या यहाँ से एक्सपोर्ट करके अपने Android मोबाइल ऐप में रीस्टोर कर सकते हैं।

iPhone / iPad पर ऐप कैसे इंस्टॉल करें

iOS Safari PWA के जरिए यह ऐप सीधे आपके iPhone की होम स्क्रीन पर बिना App Store के फुलस्क्रीन ऐप की तरह काम करता है:

1
Safari में खोलें
iPhone पर इस लिंक को Safari ब्राउज़र में खोलें (Chrome या अन्य ब्राउज़र में 'Add to Home Screen' सीमित होता है)।
2
Share बटन दबाएं
सफारी के नीचे वाले टूलबार में Share आइकन (चौकोर बॉक्स जिसमें ऊपर की तरफ तीर ⎋ है) पर टैप करें।
3
'Add to Home Screen' चुनें
नीचे स्क्रॉल करें और "Add to Home Screen" (⊕) पर टैप करें, फिर ऊपर दाईं ओर "Add" दबाएं।
✅ ऑफलाइन तैयार: एक बार होम स्क्रीन पर जुड़ने के बाद यह बिना इंटरनेट के भी खुलता है और आपका डेटा सुरक्षित रखता है।

Vercel पर 1-क्लिक रीडिप्लॉयमेंट

इस प्रोजेक्ट में vercel.json, PWA manifest.json और APK डाउनलोड रूट्स पहले से तैयार हैं।

विधि 1: GitHub + Vercel Dashboard (अनुशंसित)
  1. इस प्रोजेक्ट को अपने GitHub अकाउंट में पुश करें।
  2. vercel.com/new पर जाएं।
  3. अपनी GitHub रिपॉजिटरी चुनें और Import पर क्लिक करें।
  4. Framework Preset में Other रखें और Deploy दबाएं।
  5. 15 सेकंड में आपको लाइव URL (उदा. family-vault.vercel.app) मिल जाएगा!
विधि 2: Vercel CLI (टर्मिनल से सीधा)
npm i -g vercel
vercel login
vercel --prod
📦 Vercel पर क्या-क्या चलेगा:
• वेब कम्पैनियन ऐप व PWA (iPhone / Android)
• /app-debug.apk रूट से Android APK का डायरेक्ट ऑटोमैटिक डाउनलोड
• SSL सर्टिफिकेट व ग्लोबल फास्ट CDN स्पीड
